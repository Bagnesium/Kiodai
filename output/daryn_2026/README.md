## Как повторить проверку

Скрипты аудита предполагают расположение этого каталога в `output/daryn_2026` исходного репозитория Kiodai. Они не запускают модель и не меняют первичные результаты. Полные первичные траектории итогового опыта приложены; для исторических пилотов указаны исходные пути в репозитории.

Из корня Kiodai выполнить `source/audit_evidence.py` и `source/prepare_supplement.py` по их полным путям в этом комплекте. Для сборки нужны Python 3.11+, python-docx, ReportLab и pypdf; использован встроенный runtime Codex. Рисунки строятся через `source/figures.py`, документы через `source/build_documents.py`, PDF экспортируются из DOCX через встроенный LibreOffice. Для PNG рисунков требуется `pdftoppm`; шрифты Times New Roman и Arial должны быть доступны. В скрипте рисунков сохранены использованные пути шрифтов macOS.

Оглавление содержит проверенные номера страниц и ссылки на разделы. После изменения текста требуется повторный экспорт PDF, обновление `data/page_map.json`, сборка DOCX и проверка `source/check_documents.py`. Проверка текста не заменяет просмотр всех страниц. Вёрстка на другом компьютере может измениться при замене шрифтов; приложенный PDF фиксирует проверенную версию.

A4, Times New Roman 12 пт, левое поле 25 мм и остальные поля 20 мм выбраны редактором. Присланные правила не задают эти параметры. Все три аннотации короче 250 слов; введение занимает одну страницу, заключение — одну.
